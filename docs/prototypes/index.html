首批原型 · 总览

本目录为「原型先行流程」（30 号 §5）的首批四件静态原型：纯 HTML + CSS，无业务 JavaScript（仅保留右上角主题切换）。设计令牌实值内联自 packages/ui/src/tokens.ts；界面文案为中文；图标为内联 SVG（24 网格 / 1.75 描边 / currentColor，无 emoji 功能图标）。

四件原型

  • 原型 01

    任务侧栏（嵌会话侧栏形态）

    工单按 person/* / working / working/queued / idle 分组，状态点 + 中文文案；结果卡回到原对话（Outbox）。

    状态点24 §7.2 / §7.328 §6
  • 原型 02

    Attention 卡 · 两形态

    站内横幅 + 飞书卡片式；一次一问，批准 / 拒绝 / 补充说明三动作，超时升级提示与三阶段态。

    一次一问24 §7.2 / §7.6
  • 原型 03

    工作台五视图 · 静态稿

    看板 + 冲突三指标；信息流实时图（卡点高亮 + 图例，Canvas 的布局静态稿）；日志摘要行 + 展开态；评测曲线；worker 检查器（子代理树 / jobs / 上下文占用 / 成本）。

    五视图一检查器30 §2 / §7
  • 原型 04

    信息流图 · a11y 等价列表视图

    Canvas 无 DOM 可读——旁挂可键盘导航的等价列表（按工单 / 按节点），屏幕阅读器与键盘用户走列表不走画布。

    a11y 补偿30 §7-1 ③

工单阶段 × 状态点 · 全原型词汇表

状态点颜色不单独承载状态，一律配文字标签（frontend-style §3 徽标规则）；「等人」态带脉动光圈，prefers-reduced-motion 下停用。

阶段词汇表：与 tasks Engine 阶段枚举对应（30 §2-1、28 §6）
状态点阶段含义侧栏文案示例
等人person/answer等发起人回答 Attention（一次一问）「等你回答 · 已等 4 小时」
等人person/approve等审批人批准（含 R3 双确认与冷静期）「等你批准 · 剩 2 小时」
等人person/accept结果已发回原对话，等发起人验收「等你验收 · 结果已回到对话」
进行中workingworker 在独立目录执行工单「进行中 · 等 worker · 22 分钟」
排队中working/queued等待并发槽位（maxWorkers，人可插队 +1 槽）「排队中 · 2/4 槽」

异常error / blocked失败或被红线拦截（deny-wins）「被拒：域外出网」

硬要求落地位置（评审对照）

30 号 §5 原型先行流程评审清单：双主题 × 三断点 × a11y
要求落点
深浅主题切换（CSS 变量）每页右上角按钮，切换 <html data-eterna-theme>；默认跟随系统 prefers-color-scheme；令牌结构与实值同 tokens.ts 的 WEBFLOW_TOKENS_CSS
1100 / 760 / 640 三断点每页样式表三处媒体查询：1100 降级标题与列宽、760 导航换行 / 布局单列、640 边距收紧 / 表格横滚
语义标题与 focus 光圈每页单一 h1、分区 h2 / h3、跳转链接（跳到主内容）；:focus-visible 统一 --et-focus-ring（3px 强调色 30% 光环）
中文文案全部界面文案；领域词（工单 / 阶段 / 等谁 / 卡点）与 24 / 27 / 28 号文档一致
无 emoji 功能图标内联 SVG symbol：复用 icon-data.ts 现有集合，新增 12 枚按 iconography 语言绘制（见页脚清单）
触控目标 ≥ 36px按钮 / 输入 / 开关最小高度 36px
prefers-reduced-motion状态点脉动、事件边流动等动效自动关闭

阅读顺序建议

  1. 原型 01：发起人视角——侧栏状态点与结果回原对话（24 §7.3 端到端叙事）。
  2. 原型 02：审批人视角——Attention 卡在判断点的唯一打扰面。
  3. 原型 03：管理员 / 专家 / 审计视角——五视图一检查器。
  4. 原型 04：信息流图的 a11y 等价列表（Canvas 拍板的补偿件）。
