原型标注

  • 嵌会话侧栏形态：「会话」与「我的工单」两个分区同栏堆叠在侧栏内；≤760px 单列时侧栏置于会话窗口上方。
  • 状态点词汇表与总览页一致：等人（琥珀脉动）/ 进行中（实心蓝）/ 排队（空心蓝）/ 空闲（灰）/ 已就绪（绿）。
  • 行结构：状态点 + 标题 + id + 阶段 + 等谁 + 耗时；「等我处理」行点击进入 Attention 卡（原型二）。
  • 结果回原对话：结果卡（文件 + 摘要）由 Outbox 发回发起渠道；验收 / 退回动作在卡上完成。
  • 静态稿声明：输入框与按钮均为静态占位，不含业务脚本。
