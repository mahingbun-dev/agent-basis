键盘与读屏约定（实现说明）

  • 全键盘可达：行、按钮为原生可聚焦元素，Tab 顺序即阅读顺序；focus 光圈 3px（--et-focus-ring）。
  • 方向键漫游：实现时两张表为 grid 漫游——上下方向键在行 / 节点间移动，回车打开；本静态稿以原生链接与按钮保证可达。
  • 状态播报：状态变化以 aria-live="polite" 播报（例：「Assignment 等待人数 2 → 3」）；卡点驻留不重复播报，避免噪音。
  • 画布等价入口：画布的 hover 提示与点击回放，在列表中均有等价物（行内「回放」按钮 / 节点展开事件）。
  • 颜色不单独承载状态：每个状态点均配文字标签（frontend-style §3 徽标规则）；卡点行另加「卡点」徽标。
