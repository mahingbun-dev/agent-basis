Attention 卡 · 两形态

Attention 只在判断点出现：一次一问，三动作——批准 / 拒绝 / 补充说明；超时自动升级。站内横幅驻留在工作台顶部，渠道卡片投递到飞书等 IM；任一渠道答复后其余渠道自动消卡。面板只显示需要人的东西，健康态不占版面（30 §1）。

文案与交互规则

  • 一次一问：同一工单同时最多一张待答卡；Attention 结构化提问，不一次抛多个问题（24 §7.6）。
  • 三动作语义：批准 = 主操作实心按钮；补充说明 = 次操作描边（结构化追问，答复回到原对话）；拒绝 = 破坏性低权重文字 + 两击确认 + 一句理由（frontend-style §1-4）。
  • R3 双确认与冷静期（24 §7.2）：资金红线类批准需二次确认，冷静期内可撤回；deny 不可被审批回翻（24 §7.5）。
  • 进度不进 IM：进度看板 / 侧栏承担，IM 只收判断点卡片；过度打扰会让人无视卡片（24 §7.6）。
  • 多渠道一致：站内横幅 / 飞书卡片 / 邮件链接任一渠道答复，其余渠道自动消卡。
  • 静态稿声明：按钮均为静态占位，不含业务脚本。
