RELEASE 0.2.1

更清楚，
也更可控

本次更新集中在你每天都会碰到的三处：会话上下文、任务工单、插件权限。另有升级配置保留的修复。

01一键清空上下文 02工单状态诚实 03插件页全员可见

会话

一个命令，重开会话

输入 /clear 清空当前会话的全部上下文。几十轮旧话题不再拖住新任务，而对话记录与文件原样保留。

  • 清空动作落审计，谁在何时清的可追
  • 会话本身不删，随时接着聊
  • 适合切换新主题前的一次彻底重置

任务

不再有「假运行中」

工单状态改为按真实回收口径判定；新任务不再绑到上一张旧单上，主会话派发走独立渠道。

  • 状态与内核一致，可信度优先
  • 历史工单自动按新口径回显

权限

插件页对全员开放

非管理员也能查看已装插件、版本与启用状态，排障不必再问管理员。启停与卸载仍由管理员执行。

  • 只读范围限方法白名单内的读接口
  • 写操作失败即拒绝，不靠前端自约束

修复

升级不再弄丢你的模型

升级重渲染现在会保留你自行新增的模型供应商。此前「模型不存在」导致对话不可用的故障不再复现。

  • 仅示意图，无需任何手工迁移
  • 升级后首轮对话即可验证
