#### 3.4.3 个人层挂载（WP4-3）

新增 `packages/access/src/mcp-personal-runtime.ts`：

```ts
export interface PersonalMcpRuntime {
  /** 删除/禁用/登出时立即摘除该用户的 live scope；幂等。 */
  disposeUser(userId: number): Promise<void>
}

export function mountPersonalMcp(ctx: Context, deps: {
  store: UserStore
  sessionOwnerOf(sessionId: string): number | undefined
  logger: Logger
}): PersonalMcpRuntime {
  const byAgent = new Map<Agent, { userId: number; scope: Scope }>()
  const byUser = new Map<number, Set<Agent>>()

  async function disposeAgent(agent: Agent): Promise<void> {
    const held = byAgent.get(agent)
    if (held === undefined) return
    byAgent.delete(agent)
    byUser.get(held.userId)?.delete(agent)
    await held.scope.dispose()
  }

  ctx.on('agent/created', async ({ agent }) => {
    const userId = deps.sessionOwnerOf(agent.session.id)
    if (userId === undefined) return
    const rows = deps.store.listEnabledMcpServers(userId)
    if (rows.length === 0) return
    const scope = createScope(ctx, agent)
    byAgent.set(agent, { userId, scope })
    let agents = byUser.get(userId)
    if (agents === undefined) byUser.set(userId, agents = new Set())
    agents.add(agent)
    const results = await Promise.allSettled(rows.slice(0, 4).map(row =>
      scope.ctx.plugin(McpClient, McpClient.Config(toClientConfig(row)))))
    for (const r of results) if (r.status === 'rejected') deps.logger.warn(r.reason)
  })
  ctx.on('agent/disposed', async ({ agent }) => { await disposeAgent(agent) })
  const assertOwned = (exec: { name: string; agent?: Agent }): void => {
    if (!exec.name.startsWith('mcp__p')) return
    const uid = ownerFromServerName(exec.name)      // p<uid>_...
    const owner = deps.sessionOwnerOf(exec.agent?.session?.id ?? '')
    if (owner !== uid) throw new Error('mcp-personal: cross-tenant tool call denied')
  }
  // 第一层：审批前拒绝，避免给错租户弹审批；第二层 execute 同构兜底。
  ctx.on('tools/pre-execute', async (exec, next) => { assertOwned(exec); return next() })
  ctx.on('tools/execute', async (exec, next) => { assertOwned(exec); return next() })
  return {
    async disposeUser(userId) {
      for (const agent of [...(byUser.get(userId) ?? [])]) await disposeAgent(agent)
    },
  }
}
```

**生命周期接线**：

- `delete` / `upsert(enabled=false)` 成功后调用 `runtime.disposeUser(userId)`：该用户
  所有 live 会话的 `mcp__p<uid>_*` 工具立即消失；

## 5. 新增模块规格

### 5.1 `mcp-personal.ts` 数据访问

`UserStore` 新增方法（结构）：

```ts
listMcpServers(userId: number): McpServerRow[]
listEnabledMcpServers(userId: number): McpServerRow[]
getMcpServer(userId: number, id: string): McpServerRow | undefined
upsertMcpServer(userId: number, input: McpServerInput): McpServerRow
deleteMcpServer(userId: number, id: string): boolean
putMcpSecret(userId: number, ref: string, plaintext: string): void
getMcpSecret(userId: number, ref: string): string | undefined
```

- `server_name` 生成：`p${userId}_${slug(name)}`，slug 只留 `[A-Za-z0-9_-]`，
  截断到 32 总长；冲突时加 4 位 hash；
- 所有查询带 `user_id` 条件，禁止“先按 id 查再判属主”返回资源存在性差异；
- 审计字段：`userId/account/serverName/transport/host/action/result`。

### 5.2 terminal 守卫清单

在 access 的策略表里新增：

```ts
const TERMINAL_UNARY_ACTIONS = [
  'terminal/close', 'terminal/create', 'terminal/environment',
  'terminal/list', 'terminal/rename', 'terminal/shells',
] as const
const TERMINAL_STREAM_ACTIONS = [
  'terminal/attach', 'terminal/retain', 'terminal/watch',
] as const
```

- 每个动作按上游参数解析 session 资源（`attach` 的 `agent`、`retain/list/watch`
  的 `sessionId` 等），再查 `store.sessionOwner`；不假设统一字段名；
- `terminal/create` 还要校验 session 存在；
- 三个 stream 动作复用 `SESSION_STREAM` 守卫（不另起流过滤）。

### 5.3 chat-import 流式记账

```ts
function recordImportSessions(
  stream: ReadableStream<Uint8Array>,
  userId: number,
  store: UserStore,
  workspaceId: string,
): ReadableStream<Uint8Array> {
  // 逐行缓冲，只解析最终 outcome 行的 outcome.value.sessionIds
  // 每个 id 幂等 recordSession(id, userId, workspaceId)；流结束/取消时用 workspace sessionIds 对账
}
```

- 不缓冲整包；单行上限 64KB，超限丢弃该行但继续；
- 解析失败不阻断上传（记录 warning 审计）；
- 取消时对账补记，避免“已写入但无主”。

### 5.4 ACP stdout 纪律

- **禁止 `exec 1>&2`**（会把 dsh 的 JSON-RPC 也赶到 stderr）；entrypoint 逐条
  `log()`/`>&2`，`exec dsh` 保留原 stdout；
- 所有 `echo`/`printf` 到 stdout 的调用改为 `>&2` 或 `log()`；
- `docker compose --profile acp run --rm -T` 驱动，`tty:false`；
- 禁止在 web 容器 `docker exec` 起 ACP 作为默认路径。

### 5.5 bundle 迁移
