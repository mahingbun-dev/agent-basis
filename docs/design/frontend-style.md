# Eterna 前端风格规范（frontend-style v2）

> 2026-11-10 起为**仓库强制规范**（见 AGENTS.md「前端与产品形态铁律」）。
> v2 定案（用户拍板）：**产品内功能一律做成设置弹窗分区插件（`settings.section` slot）**，
> 不自建独立页面；UI 用 DSH 官方语义令牌 `--dsw-alias-*`（深浅自动跟随产品）。
> 参考实现：`packages/access/src/client/`（三分区）+ `packages/panel/src/client/`（面板先例）。
> v1 的自建页令牌表仍适用于 /login 登录门禁页（唯一例外，`packages/access/src/pages.ts`）。

## 0. 为什么有这条规范

用户原话（2026-11-10）：「这些功能，都应该是插件。这些开发的规则，都应该写在仓库」。
dsh 的设置弹窗就是为插件分区设计的（上游原话：adding a setting never means editing
the shell）——自建独立页面（v1 形态）既割裂风格又重复导航。v2 定案：功能进弹窗分区，
UI 走官方令牌，风格统一由产品壳保证。

## 1. 铁律（违反 = 审查打回）

1. **主题令牌化**：颜色只允许用 §2 令牌（CSS 变量），禁止硬编码色值（品牌渐变头像
   `#6366f1→#8b5cf6` 除外）。新增颜色 = 先改令牌表再使用。
2. **双主题**：深色为默认基调（匹配 dsh 应用底色）；浅色经 `prefers-color-scheme: light`
   整套适配。任何页面不允许只出一套色。
3. **骨架复用**：独立页面必须复用 access `shell()` 同构骨架——sticky 毛玻璃 topbar
   （品牌=返回应用 ｜ 身份头像+昵称+账号设置+退出）+ main 居中卡。禁止再造导航。
4. **交互一致**：
   - 主操作 = 渐变主按钮；次操作 = ghost 描边按钮；破坏性操作 = 红字 + 两击确认
     （禁用原生 `confirm()/alert()`——内嵌 webview 卡死实测）；删除类必须两击。
   - 表单：label 在上、输入聚焦 accent 光圈、错误红字就地显示、成功绿字就地显示。
   - **合并保存**：同一卡片的资料类字段共用一个「保存更改」按钮（脏检查驱动，无改动
     禁用）；密码等安全敏感操作独立成卡，永不与资料保存捆绑。
   - 变更类请求防重复点击（提交即禁用按钮）；页面 `cache-control: no-store`。
5. **可访问性**：`lang="zh-CN"`、语义标题、`:focus-visible` 光圈、
   `prefers-reduced-motion` 降级、触控目标 ≥36px。
6. **响应式**：640px 断点内单列自适应；topbar 收窄（昵称隐藏）。

## 2. 令牌表（唯一色源）

| 令牌 | 深色（默认） | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--bg` / `--bg-a` / `--bg-b` | `#151517` / `#1b1b20` / `#151517` | `#eef0f6` / `#eef2ff` / `#f8fafc` | 页面底 + 渐变 |
| `--surface` / `--surface-2` | `#1e1e23` / `#26262c` | `#ffffff` / `#f3f4f6` | 卡片 / 输入与表头 |
| `--text` / `--dim` | `#f3f4f6` / `#9ca3af` | `#111827` / `#6b7280` | 正文 / 次要 |
| `--border` | `rgba(255,255,255,.09)` | `rgba(17,24,39,.10)` | 边框 |
| `--accent` / `--accent-strong` / `--accent-soft` | `#818cf8` / `#6366f1` / `rgba(99,102,241,.18)` | `#4f46e5` / `#4338ca` / `rgba(79,70,229,.12)` | 主操作/焦点/标签 |
| `--danger` / `--ok` | `#f87171` / `#34d399` | `#dc2626` / `#059669` | 错误 / 成功 |
| `--shadow` | 双层深投影 | 双层浅投影 | 卡片 |

品牌渐变（头像/角标字母）：`linear-gradient(135deg,#6366f1,#8b5cf6)`——唯一豁免硬编码。

## 3. 页面骨架

```html
<body>
  <header class="topbar">…品牌(返回应用) + 身份/导航/退出…</header>
  <main>…<div class="card wide">…</div>…（stack 纵列）…</main>
</body>
```

- 卡片宽度：窄卡 `min(420px,94vw)`（登录/无权），页栈 `min(560px,94vw)`（账号/管理）。
- 一个功能域一张卡；卡内标题 `h3`；页面主标题 `h2` 只在栈首卡。
