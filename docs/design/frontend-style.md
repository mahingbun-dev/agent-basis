# Eterna 前端风格规范（frontend-style v3）

> 2026-11-11 起为仓库强制规范（见 AGENTS.md「前端与产品形态铁律」）。
> v3 定案：统一采用 **Webflow 设计语言**作为视觉基底，令牌集中在
> `packages/ui/src/tokens.ts`；应用内插件面经 DSH 语义令牌跟随产品深浅主题，
> 独立页（登录/扩展设置）使用 Webflow 浅色 + 系统深色。
> 参考实现：`packages/ui` + `packages/access/src/client/styles.ts`。

## 0. 为什么是 Webflow

用户原话（2026-11-11）：「风格统一，简约、高级。包括排版和交互」。
审查发现四套页面语言并存（Apple 编辑风 / 原生插件卡 / 通用仪表盘 / 独立页），
根因是每页各自定义字号、圆角、按钮和容器。Webflow 体系提供完整且可执行的
约束：近黑文字 + 单一 Webflow Blue、4/8px 锐角、五层级联阴影、16px 标准正文、
克制的字阶与留白。它比继续维护自定义紫色/18px 圆角更稳定，也更工具化。

## 1. 铁律（违反 = 审查打回）

1. **令牌唯一**：颜色、字号、间距、圆角、动效只允许引用 `--et-*`；
   十六进制色值只允许出现在 `packages/ui/src/tokens.ts`。
2. **双主题**：应用内插件面必须经 `DSH_BRIDGE_CSS` 跟随产品主题；独立页
   使用 `WEBFLOW_TOKENS_CSS`（浅色 + `prefers-color-scheme: dark`）。
   任何页面不允许只出一套色。
3. **骨架复用**：功能进设置弹窗分区（`settings.section` slot）；独立页复用
   `shell()` 骨架。禁止再造导航。
4. **交互一致**：
   - 主操作 = 实心 Webflow Blue；次操作 = 描边/ghost；破坏性操作 = 低权重
     文字 + 两击确认，禁止用错误红表示保存。
   - `:focus-visible` 统一 `0 0 0 3px` 强调色 30% 光环；触控目标 ≥36px。
   - 同一卡片的资料类字段合并保存；变更请求防重复点击；页面 `no-store`。
5. **可访问性**：`lang="zh-CN"`、语义标题、`prefers-reduced-motion`、
   错误/成功就地显示并带 `role="alert"` / `aria-live`。
6. **响应式**：应用内页面 960px 容器、设置 720px、独立表单 440px；
   640px 断点单列，表格必须可横向滚动。

| 类别 | 令牌 | 规则 |

| 文字 | `--et-fg` / `--et-fg-2` / `--et-muted` / `--et-meta` | 近黑 / 正文 / 辅助 / 占位 |
| 边框 | `--et-border` / `--et-border-soft` | 卡片 / 行分隔 |
| 强调 | `--et-accent` / `--et-accent-fill` / `--et-accent-soft` | 链接与焦点 / 实心按钮 / 浅底；实心按钮白字须过 4.5:1 |
| 语义 | `--et-success` / `--et-warn` / `--et-danger` | 状态与破坏性操作 |

## 3. 组件规则

- **按钮**：实心主按钮（`--et-accent`，4px，10×16 内距）；次按钮描边；
  ghost 用于低权重；破坏性操作用 `--et-danger` 文字，两击确认。
- **输入**：12×14 内距、4px、1px 边框；聚焦蓝色边框 + 光环；错误就地显示。
- **卡片**：1px `--et-border-soft`、4px、20–24px 内距、`--et-surface`；
  独立页卡片可用五层阴影，应用内列表卡不使用重阴影。
- **徽标**：4px、强调色 10% 底、12px/600；状态色必须配文字，不得只靠颜色。
- **表格**：14px、表头 12px 辅助色、行间 `--et-border-soft`、数字 tabular；
  外层 `overflow-x:auto`。
- **开关/分段**：开关 36×20，命中区 ≥36px；分段选中态只用强调色或浅底。
- **弹窗/菜单**：8px、24px 内距、五层阴影、焦点陷阱。
- **图标**：统一官方 `ui-primitives` 线性图标；禁止 emoji 作为功能图标；
  品牌标只保留一枚 SVG，`currentColor` 跟随主题。
