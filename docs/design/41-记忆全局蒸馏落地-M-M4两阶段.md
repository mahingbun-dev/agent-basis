## 2. 配置键(真相源与热改面)

| 键 | 位置 | 缺省 | 消费方 |
|---|---|---|---|
| `distill.enabled` | profile patch `MemoryPluginConfig.distill`(部署基线) | false | `resolveDistillGate` |
| `distill.minUsers / intervalHours / model` | 同上(部署旋钮) | 5 / 24 / Flash | glue wireConsolidation |
| `distillEnabled` | **部署根** overrides(`<DSH_HOME>/.eterna/memory.config.json`) | 缺席 | 热改键,覆写基线(admin UI「部署开关」写) |
| `distillMinUsers` | 同根 overrides | 缺省 5;**本部署配 3** | glue apply 解析一次,**改后重启插件生效**(部署旋钮非热改键) |
| `distillParticipate` | **各账号** overrides(`workspaces/<账号>/.eterna/memory.config.json`) | true | 聚合任务逐账号现读;设置分区「参与全局蒸馏」写 |

关键接线事实:生产 bundle 走 `@eterna/glue/memory-plugin` 的 **default export(无 config 注入)**,故蒸馏接线**恒挂**、门双缺省关——授权链完全由根 overrides `distillEnabled` 承载(admin UI 开启 = 管理员授权,Q4)。已知限制:蒸馏随整固接线挂载,`consolidation.enabled=false && dream.enabled=false` 的部署蒸馏同样不可用(全量回滚面语义)。

## 3. 数据流

```
turn/end(completed) ──> SessionEndConsolidator
  ├─ 轻量提取(既有)
  ├─ maybeEnqueueDream('dream' 伪会话游标,既有)
  └─ maybeEnqueueDistill('distill' 伪会话游标,M-M4 新增;间隔缺省 24h)

distillTask(createDistillJob 组合):
  Phase A(distill.ts,零 LLM):
    全量账号遍历(不分片——Dream 的 >20 日分片是重 LLM 成本合并,分片致计数偏差)
    → 跳过 distillParticipate=false 账号
    → 逐账号 readOnly sqlite 快照(approved 且未失效,≤500 条按 last_used_at 截断)
    → tokenOverlapRatio 贪心单遍聚类(阈值 0.6,CJK 逐字+ASCII 分词同口径)
    → 独立账号数 ≥K 才列簇;参与账号 < K → sampleSufficient=false 如实标注
    → PII 掩码(BuiltinPiiGuard.scan 命中区间替换,掩码不拒绝)
    → 落盘 $DSH_HOME/memory-distill/{latest.json(原子写), report-<UTC日期>.json, runs.jsonl}
  Phase B(distill-curate.ts,每簇一次 LLM,≤3 簇/次;模型不可用走模板回落):
    拷骨架 → 起草 add_entry(蒸馏专用提示词,非 evolve 失败簇口径;mastLabel 缺省 F1 如实回落)
    → 模型诚实 skip → 不建候选目录
    → 候选目录 candidates/<id>/(完整可 lint 的 pack 拷贝)
    → runGates 整包跑:G0 packctl lint → G1 evals replay 冒烟 → G2 降级跳过(明示)
    → 三查探针(fail-closed)→ 全过 → ledger markVerified(待签发)
```

调度器语义增量(`consolidation.ts`):`jobKind:'distill'` 与 `'dream'` 同款——error/abort 不推进游标、被顶掉不虚假推进;**周期任务 pending 粘滞**(M-M4 引入顺序回归的修复):同 kind 重入才覆盖,session/另一周期任务不顶掉——否则同一会话尾上后入队的蒸馏会系统性挤掉先入队的 Dream。单跑测试 162/162 钉住(`tests/consolidation.spec.ts`)。

## 4. 门禁与探针(Phase B,fail-closed)

| 关卡 | 实现 | 降级如实声明 |
|---|---|---|
| G0 lint | evolve `runGates`(packctl 库调用),对候选目录整包跑 | 无 |
| G1 replay | evolve `runGates`,骨架自带 `evals/golden/distill-smoke.yaml` + `fixtures/distill-smoke.jsonl`(replay 适配器吃 fixture 物化文件断言) | 无 |
| G2 ai-evo 三层 | evolve 原生 degraded 跳过(**账本 verification.g2 明示 skipped**) | ai-evo 未接入(M-E0 baseUrl/Key 待定),接入后自动生效 |
| 三查探针 | `runDistillProbes`:①PII 残留(BuiltinPiiGuard 同源四模式)②租户残留(参与账号名字面/绝对路径/`DSH_HOME|ETERNA_TENANT_ROOT|workspaces/`)③注入模式(「忽略之前指令」类中英正则) | 本地确定性,恒可跑;**probe=fail 的候选签发按钮禁用** |
| 跨用户 ≥K | Phase A 聚合已按独立账号数过滤 | 冷启动样本不足只标注不产候选 |
| SME 人签发 | `releaseDistillCandidate`:ledger verified + **签发时探针复检**(TOCTOU 防线)→ `approveAndRelease` → 产物 `release/<id>.skill.md` | **合入 packs/ 仓库是人工 git 动作**(09/10 号「人审合并在外层 PR 式」原文纪律),本模块绝不写 packs/ |

拒绝语义:账本无 rejected 态(不新增),meta 记 `decision:{action:'rejected'}`;清单默认排除已拒绝,`includeRejected` 显式带出。

## 5. 服务面与 UI

- **八个新 SRC 端点**(`admin-plugin.ts`,宿主挂载行不变):`distillView`(登录即可) / `setDistillParticipate`(登录,写本人账号 overrides;无库账号经 `memoryForAccount` 懒开通保证退出意向持久) / `distillReport`(admin) / `distillEnable`(admin 授权链) / `distillRun`(admin,转发 glue `'eternaMemoryDistill'` face 的 `runNow`,单飞守卫) / `distillCandidates` / `distillCandidateRelease` / `distillCandidateReject`(均 admin)。
- **设置分区**(settings.section,不变 slot):蒸馏字段三态——部署关=禁用+「部署未开启」;部署开=默认勾选可退出(hint 即隐私声明);策略三键维持 admin 门禁,非 admin 渲染 distill-only 卡(Q4「设置分区提供用户级 opt-out」)。
- **plugins.tab「全局蒸馏」页签**(id `eterna-memory.distill`,order 46,18 §10「admin 报告页」):部署开关(开启**两击确认**+隐私声明常驻)、运行状态(计数+样本不足标注+手动运行)、聚类表、候选区(状态 chip、门禁摘要含 G2 skipped 明示、探针态、正文预览、签发两击/拒绝)。
- 产物隔离:`$DSH_HOME/memory-distill/`(与 access/、sessions/ 同级,不在任何租户根下,不经任何 agent 上下文);packctl tenant-scan 随 DSH_HOME 语义覆盖。
