## 0. 使用说明

### 0.1 优先级

| 级别 | 含义 | 处置 |
|---|---|---|
| **P0** | 阻断发布：安全隔离、数据完整性、启动/登录、核心链路 | 任一失败 → 停止，不进生产 |
| **P1** | 功能正确性：新能力主路径、兼容性、UI 主路径 | 失败可带已知问题发布，须产品书面签字 |
| **P2** | 健壮性/体验：边界、提示、性能、可维护性 | 记录，不阻断；下个迭代修 |

### 0.2 执行方式

| 代号 | 含义 |
|---|---|
| **A** | 全自动：脚本/单测/CI，退出码即结论 |
| **S** | 半自动：脚本准备 + 人工读结果/截图比对 |
| **M** | 人工：浏览器/终端操作，按步骤记录 |

### 0.3 证据规范

- 根目录：`artifacts/rc5/<suite>/<case-id>/`
- 必含：`cmd.log`（命令与退出码）、`result.md`（实际 vs 预期）、截图/DB dump（按用例）；
- 截图命名：`<case>-<theme>-<width>.png`，主题 `light|dark`，宽度 `1440|900|390`；
- **禁止**把 cookie、token、MCP headers、密钥明文写入证据；日志先过 redaction；
- 失败用例保留原始日志，不裁剪。

### 0.4 环境矩阵

| 环境 | 用途 | 约束 |
|---|---|---|
| **E0 本地 worktree** | 编译/单测/静态门禁 | 不连生产 |
| **E1 隔离测试容器** | boot、MCP、terminal、office、chat-import | 独立端口 `3108`、独立数据根 `$HOME/eterna-data/test-<date>`；用 `ETERNA_CONTAINER_NAME/ETERNA_PORT/ETERNA_INSTANCE` 覆写，禁止撞固定容器名 |
| **E2 双账号浏览器** | 租户隔离、UI | A/B/C 三账号；A=管理员，B/C=普通用户 |
| **E3 super 形态** | super 面板、tasks、terminal | 独立容器/独立根 |
| **E4 ACP stdio 夹具** | ACP 协议/纯净性 | `docker compose run -T`，无端口 |
| **E5 迁移演练** | 旧卷 → 新根 | 生产数据**副本**，绝不操作生产卷 |
| **E6 生产窗口** | 上线后验证 | 只跑 `verify.sh` + 只读冒烟 |

> **铁律**：E1/E3/E5 全部用独立容器与独立数据根；不得为测试重启/改配置生产容器。

## 2. 执行顺序

1. **E0 静态门禁**：ENV / API / ACC / V1 / UI-tokens / SEC-static；
2. **E1 隔离容器**：BOOT / MCPS / MCPP(路由+挂载) / TERM / IMP / OFF / CMD / HERO；
3. **E2 双账号浏览器**：MCPP(隔离+UI) / ACC / TERM / UI / SEC；
4. **E3 super**：BOOT-super / tasks / terminal / workbench；
5. **E4 ACP**：ACP 全组；
6. **E5 迁移**：DATA 全组；
7. **E6 生产**：仅 `verify.sh` + 登录/对话/文件/记忆冒烟。

任何 P0 红 → 停在该阶段，回 50 §9 回滚；不得跳阶段。

## 7. 失败处置

| 现象 | 首查 | 处置 |
|---|---|---|
| boot 失败/未知行 | profile 渲染、bundle 版本 | 回滚该 WP；不得带病启动 |
| 跨租户可访问 | `sessionOwner`/`workspaceOwner`、路由归属 | **立即停止**；按安全缺陷处理 |
| 个人 MCP 串号 | `serverName`、scope 键控、`agent/created` | 停用个人层（kill switch），回滚 |
| terminal 越权 | 9 动作归属、`readUserTerminals` | 关 bundle，回滚 |
| chat-import 孤儿会话 | 流式记账/对账 | 补记账脚本；不可上线 |
| ACP stdout 污染 | 全局 `exec 1>&2`（误伤 JSON-RPC）、日志调用 | 改为逐条 stderr；修复后重跑 ACP 全组 |
| 数据损坏 | `integrity_check`、迁移脚本 | 停写；从冷备恢复；回滚 |
| UI 破面 | 令牌/断点/主题 | 修复后重截三视口 |
