## 2. 文件级改动清单

### 2.1 `packages/access/src/thinking-score.ts`（C1）

```ts
export interface ThinkingSessionSignals {
  readonly toolFailureStreak: number       // 最近 3 轮内失败 tool/result 数（封顶计入 2）
  readonly sameToolFailureStreak: number   // 同一工具连续失败次数（≥2 触发）
  readonly followUpOverlap: number         // 与上一条 user/message 的字符二元组重叠 [0,1]
  readonly followUpGapMinutes: number      // 两条用户消息的间隔（分钟）
  readonly windowEvents: number            // 窗口内事件数
  readonly recentChars: number             // 最近 3 条 user+assistant 文本总字符
  readonly previousEffortRank?: number      // 上轮档位归一 [0,1]（0=最低档）
  readonly bias: number                    // 有效偏置（已衰减）[-0.5,0.5]
}
export interface ThinkingScoreInput { text: string; hasAttachment: boolean; signals?: ThinkingSessionSignals }
```

- 常量（头部集中）：`TOOL_FAILURE_BONUS=0.15` / `TOOL_FAILURE_CAP=0.3` / `SAME_TOOL_BONUS=0.15` / `FOLLOW_UP_BONUS=0.15` / `FOLLOW_UP_MIN_OVERLAP=0.6` / `FOLLOW_UP_MAX_GAP_MIN=10` / `SCALE_EVENTS=200`+`0.1` / `SCALE_CHARS=20000`+`0.1` / `PREV_EFFORT_WEIGHT=0.05` / `BIAS_CLAMP=0.5`
- 顺序：显式指令 → 寒暄钳制 → 基础信号叠加 → 上下文信号叠加 → 上轮档位弱先验 → 叠加偏置 → 钳 [0,1]
- 新增纯函数：`decayBias(bias, updatedAtMs, nowMs)`（24h 半衰）

### 2.2 `packages/access/src/thinking-context.ts`（新，C1）

只做「事件 → 信号」的纯变换，零 I/O、零 import 宿主类型：

```ts
export interface SessionEventLike { readonly type?: unknown; readonly data?: unknown; readonly at?: unknown }
export function textOverlap(a: string, b: string): number       // 字符二元组 containment
export function deriveSessionSignals(events: readonly SessionEventLike[], nowMs: number): Omit<ThinkingSessionSignals,'bias'|'previousEffortRank'>
```

解析：`tool/result`（`data.message.isError===true` / `data.error`）、`user/message`（`data.message.content` 文本块或 `data.content`）、事件时间（`event.at` 或 `data.at`，缺省用 now 兜底）。

### 2.3 `packages/access/src/store.ts`（C2）

- `migrateSessionsThinkingBias(db)`：幂等补 `thinking_bias REAL NOT NULL DEFAULT 0`、`thinking_bias_at INTEGER NOT NULL DEFAULT 0`；构造器调用。
- `thinkingBiasOf(sessionId): { bias: number; updatedAt: number } | undefined`
- `addThinkingBias(sessionId, delta, now): { bias: number } | undefined`：读改写、`Math.max(-0.5, Math.min(0.5, …))`、未知会话返回 undefined（不建行）。

### 2.4 `packages/access/src/thinking-auto.ts`（C3）

- `ThinkingAutoStore` 增 `thinkingBiasOf`。
- `InboxInsertedPayload.agent` 增 `session?: { id?: unknown; snapshotEvents?(from, to): readonly unknown[]; seq?: unknown }`。
- 新增 `readSessionWindow(agent, now)`：`seq` 已知则取 `[max(0, seq-200), seq)`，否则 `snapshotEvents(0, owned?)` 截尾；任何异常→空窗口（fail-neutral）。
- 评分调用改为 `scoreMessage({ ...body, signals })`；审计 detail 增 `toolFailures/sameToolFailures/followUpOverlap/windowEvents/bias/previousEffort`。
- 仍是全同步；select 前不做任何 await。

### 2.5 `packages/access/src/plugin.ts`（C3）

`installThinkingAuto({ store, llm: ctx.llm, audit })` 不变（store 实现新增方法即满足接口）。

### 2.6 `packages/access/src/tenant.ts`（C4）

```
POST /api/session/thinkingFeedback
request: { sessionId, messageId, direction: 'less'|'more' }
→ { bias, effectiveBias }
```

- 归属：`store.sessionOwner(sessionId) !== ctx.userId` → denied（同 thinkingAuto 先例）。
- `direction` 白名单外 → denied('direction 无效')。
- 写：`addThinkingBias(sessionId, direction==='less'?-0.2:+0.2, Date.now())`。
- 审计：`thinking.feedback`，detail `{ sessionId, messageId, direction, bias }`。

### 2.7 客户端（C5）

- 新文件 `client/thinking-feedback.tsx`：组件 `ThinkingFeedbackActions({ messageId })`，sessionId 取 `localStorage['dsh.sessions.current']`（与 `readCurrentSession` 同源），两枚文字按钮「想浅点」「想深点」。
- 注册：`index.tsx` 中 `ctx.slots.inject('conversation.chat.assistant-actions', () => ctx.slots.register({ name:'conversation.chat.assistant-actions', locale: NS, ... }, ThinkingFeedbackActions))`。
- 交互：请求中 disabled（防重复）；成功后按钮短暂显示「已调浅/已调深」(`--et-success` 令牌)；失败就地 `role="alert"` 文案；不阻塞对话。
- 样式：`--et-*` 令牌；focus 光圈；`prefers-reduced-motion`；深浅主题自动跟随（DSH 桥）。
- 无新页面、无字面色值、无手写 SVG（纯文字按钮）。

### 2.8 脚本与文档（C6）

- `scripts/thinking-sample.mjs`：`--src <session-jsonl 目录> --out <corpus.jsonl> --limit N`；解析 jsonl 每行事件，抽 `user/message` 文本 + 前 200 事件窗口摘要；PII 脱敏复用简化规则（邮箱/手机号/证件号）。
- `scripts/thinking-replay.mjs`：读语料（含 `targetEffort`），对每个模型档位集跑 V1（`signals` 省略）与 V2（含 signals），输出相邻档命中率/一致率/极端误配计数/混淆矩阵；`--gate` 断言 `相邻档≥0.9 && 一致率≥0.6 && 极端误配==0`。
- `docs/dev/thinking-auto.md`：追加 V2 语义、信号表、偏置口径、RPC 契约、验证口径。
