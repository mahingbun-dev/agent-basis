## 1. 逐项设计与验收

### F1 菜单会话 id 不正（medium）

**问题**：模型菜单（body 级命令式挂载）用 `localStorage['dsh.sessions.current']`，多 tab/多会话下可能操作到另一会话的偏置。

**方案（无 UI 的会话桥）**：
- 新增 `client/session-bridge.ts`：模块级 `activeSessionId` 读写（不持久化）。
- 新增 `SessionBindingProbe` 组件：注册到 `conversation.input.overlay`（ui-conversation 声明，`list` + `scope:'session'`，sessionId 由 ui-session 标准席位作为普通 prop 下发），渲染 `null`，仅在 `useEffect` 里写入桥。
- 菜单打开时取 `activeSessionId() ?? readCurrentSession()`；反馈按钮取 `props.sessionId ?? activeSessionId() ?? localStorage`。

**验收**：单测（桥纯逻辑）、构建通过；E2E 在多会话场景不回归（现脚本单会话，记录为未覆盖的多 tab 场景）。
**残余风险**：`conversation.input.overlay` 未装载（极老壳）时回退 localStorage，与今日行为一致。

### F2 偏置显示阈值与判档死区不一致（medium）

**方案**：新增纯模块 `client/bias-view.ts`：`BIAS_VISIBLE_MIN = 0.01`（与 `thinking-score.BIAS_DEAD_ZONE` 同值，注释互相引用）、
`biasVisible(v)`、`biasLabel(v)`（两位小数，`已调深 +0.04` / `已调浅 0.04`）。菜单改用该模块，删除「四舍五入到 0.1」。
**验收**：`tests/bias-view.spec.ts` 覆盖 ±0.009/±0.01/±0.04/±0.2/±0.5 与 ±0 的显示。

### F3 重置按钮触控目标 <36px（medium）

**方案**：`.ea-bias-reset` 设 `min-height: 36px`（`padding: 0 12px`，垂直居中），与 `frontend-style.md` §触控目标一致；
chip 行本身保持内联，不设 36（非交互元素）。
**验收**：样式令牌 lint 绿；复核清单人工核对（无自动化高度断言）。

### F4 偏置行不受自动开关门控（medium）

**方案**：菜单把 `autoOn` 传给偏置行；`autoOn === false` 时行内显示可见文案
「自动选档已关闭，偏置暂不参与判档」（不再只藏在 title），重置按钮仍可用（先清再开）。
**验收**：行内文案在 `autoOn === false` 时出现（代码走查 + E2E 可选断言）。

### F5 reset 审计丢失原始偏置（medium）

**方案**：`tenant.ts` reset 分支审计改为三键：`previousBias`（原始落库值）、`previousUpdatedAt`（epoch ms）、
`previousBiasEffective`（衰减后）。注释同步。
**验收**：`tenant.spec.ts` 构造「写入 0.4、间隔 24h 后 reset」→ 审计 `previousBias≈0.4`、`previousBiasEffective≈0.2`。

### F6 E2E 未覆盖读/reset 支路（medium）

**方案**：`p7-e2e-thinking-feedback.mjs` 的头部口径改为「被测代码 = 指定 SHA，含读/reset」；
新增用例：读支返回 `{bias,effectiveBias}` 且 `bias≥effectiveBias`；RPC reset 归零并出 `direction=reset` 审计；
UI 重置（菜单两击）后行消失、读回 0。
**验收**：脚本静态自检（`node --check`）+ 新分支代码锚点断言；运行需 Docker，列入未覆盖。

### F7 截图为动作条、缺偏置行（medium）

**方案**：菜单打开后截 `[data-eterna-model-menu-root]` 的偏置行（含重置按钮），输出 `bias-row-{light,dark}.png`；
保留原动作条截图。
**验收**：脚本存在两处截图；实际 PNG 需运行环境（未覆盖）。

### F8 偏置行异步出现后定位不纠正（low）

**方案**：把「below→above」单向纠正改为双向纠正（每次 rect 变化都按视口选上/下），
且 `mainRect` 测量 effect 的依赖加 `biasShown`（行出现/消失后重算子面板基准）。
**验收**：代码走查；无 DOM 测试环境，记录为未自动化。

### F9 重置失败透传英文（low）

**方案**：失败统一显示中文固定文案「重置失败，请稍后重试」（`role=status aria-live=polite`），
原始错误只进 `console.warn`（不展示）。
**验收**：代码走查（`e.message` 不再进入 UI）。

### F10 拒绝路径不落审计（low）

**方案**：`thinkingFeedback` 的归属拒绝、direction 非法、messageId 超长都记
`thinking.feedback.denied`（detail：`reason`，`sessionId` 能取到就带）。读支仍不记（避免菜单打开刷审计）。
**验收**：`tenant.spec.ts` 断言三种拒绝各产一条 denied 审计。

### F11 messageId 不校验（low）

**方案**：`messageId` 必须是字符串且 ≤128 字符；超长/类型错 → 拒绝（`messageId 无效`）+ denied 审计。
不校验存在性（access 无消息访问面，越权由 sessionOwner 挡）。
**验收**：单测覆盖 129 字符拒绝、缺省放行。

### F12 direction 键名拼错静默落入读支（low）

**方案**：分流按「键存在性」且做近似键识别：`direction` 精确键之外的 `/^dir/i` 键 → 拒绝（`direction 无效`）+ denied 审计；
值非字符串（`''`/数字）同样拒绝。`thinkingAuto` 同步统一：`enabled` 键存在但非布尔、或 `/^enabl/i` 近似键 → 拒绝。
**验收**：单测覆盖 `directon`、`direction:''`、`enabled:''`。

### F13 字号字面值（low）

**方案**：`styles.ts` 两处 `font-size: 12px` → `var(--et-text-micro)`。
**验收**：令牌 lint 绿。

### F14 客户端零测试 / 服务端分支未断言（low）

**方案**：
- `client/bias-view.ts` 纯逻辑单测（F2）；
- `tenant.spec.ts` 增：读支随 24h 衰减（构造旧 `updatedAt`）、reset 不动 `thinking_auto`、
  拒绝审计、messageId、方向拼错；
- `tenant-guard-matrix.spec.ts` 增 `thinkingAuto`/`thinkingFeedback` × {本人/他人/未登录} 六例。
**验收**：包级 verify 全绿且新增用例可枚举。

### F15 重置按钮缺菜单语义（low）

**方案**：`TwoClickButton` 增可选 `ariaLabel?`、`role?`；偏置行传 `role="menuitem"`、
`aria-label="重置本会话思考偏置"`。
**验收**：代码走查（DOM 断言无测试环境）。

## 3. 契约变更（服务端）

```
POST /api/session/thinkingFeedback
  {request:{sessionId}}                                → {bias, effectiveBias}（只读，不审计）
  {request:{sessionId, messageId?, direction:'less'|'more'}}
                                                       → {bias, effectiveBias}（±0.2）
  {request:{sessionId, messageId?, direction:'reset'}} → {bias:0, effectiveBias:0}
拒绝（均审计 thinking.feedback.denied）：
  - 会话不存在/不属于当前用户（reason:'owner'）
  - direction 非法值 / 近似键拼错 / 非字符串（reason:'direction'）
  - messageId 非字符串或 >128 字符（reason:'messageId'）

POST /api/session/thinkingAuto
  enabled 键存在但非布尔、或近似键（/^enabl/i）→ 拒绝 + denied 审计（reason:'enabled'）
```

## 5. 风险

| 风险 | 对策 |
|---|---|
| overlay 探针在 list slot 渲染 null 可能影响布局 | 返回 null 不产生 DOM；E2E 首屏回归检查 |
| 拒绝审计增加审计量 | 只记拒绝（探测痕迹），读支不记 |
| `thinkingAuto` 严格化可能影响旧客户端 | 旧客户端发布尔；严格化只在键存在且非布尔时触发 |
| E2E 改动无法本机验证 | `node --check` 语法 + 锚点断言；运行留待容器环境 |
