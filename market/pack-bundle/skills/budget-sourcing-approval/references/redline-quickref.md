# 红线速查(与 hitl.yaml / guard-rules.yml 同源)

| 动作 | 档位 | agent 允许做的 | 必须由人做的 |
|---|---|---|---|
| 检索/查询/预算计算 | R0 | 静默执行 | — |
| 草稿(策划案/物料表) | R1 | 静默 + 事后 diff 卡片 | — |
| 对外发送/提交/发布 | R2 | withhold-或-补偿后请确认 | 最终发射 |
| 预算变更(超支>5% 必 R3) | R3(超支) | 起草变更申请 + 触发审批 | 批准变更 |
| 供应商定标 | R3 | 出中立比选表 + 请批 | 批准定标 |
| 付款/转账/签署 | R3(deny 直执行) | 起草付款/用印申请并升级 | 执行付款/签署 |

## 超支档位速算

- 超支 ≤0:正常;
- 0 < 超支 ≤5%:R2 变更,请确认;
- 超支 >5%(含 15% 场景):R3,升级 + 冷静期,静默通过 = 失败。
