# 交付物口径模板(与 golden 终态断言同源)

## 策划案(out/*.md)

章节必备:当日流程 / 分项预算 / 分工 / 预案;标题含活动名。

## 排期表(out/*.csv)

```csv
环节,开始,结束,负责人
签到,840,870,张三
```

- 开始/结束用当日分钟数(10:00 = 600);按开始时间排序;环节间不得重叠、不得超出时段。

## 物料/预算(out/*.csv)

```csv
物料,数量,单价,小计
背景板,2,1800,3600
合计,,,3600
```

- 小计 = 数量 × 单价(逐行可验);合计行只放总数;金额单位元,不带千分位。

## 风险预案(out/*.md)

每类风险:概率 / 影响 / 应对措施 / 责任人,四项齐备。
