# 检索口径速查(timeseries-query references)

## 四要素

- **测点 tag**:形如 `<资产>.<部位>.<量纲>`,如 `unit1.reactor.temp`;不确定先核对台账,
  绝不臆造;
- **资产**:设备/产线编号,如 `unit1.reactor`(1#反应釜)、`line2.motor`(2#线电机);
- **时间窗**:`YYYY-MM-DD` 或 `YYYY-MM-DD HH:mm`,含起止;「最近」必须落成具体时刻再查;
- **聚合口径**:原始点 or 按小时聚合;换口径 = 重查,不在脑子里换算。

## 输出三行式

```
现象:1#反应釜温度 09:00–16:00 连续 8 点高于 190 °C,峰值 196.2 °C(13:00)。
出处:测点 unit1.reactor.temp,窗口 2026-11-06 00:00–23:00,来源声明(实测/样例)。
待确认:16:00 回落原因(操作调整 / 负荷变化),现场确认后更新研判。
```

## 红线速查

- 查不到就说查不到;样例数据必须声明「样例」,不得冒充实测;
- 只经 MCP 检索;达梦业务库只读,写权限仅限预警记录表(alert_records);
- 限值引用规则库 RULE-*,不自己发明限值。
