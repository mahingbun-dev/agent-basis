# 引用与无命中话术速查(knowledge-qa references)

## 引用格式(出处与版本,逐字不改写)

- 用 kb_search 命中返回的 `citation` 串原样引用:
  `《2#线电机轴承振动维护手册》 v2026.09(equipment-manuals/MAN-MOTOR-VIB-001,更新于 2026-09-30)`;
- 一条结论一个出处;多来源分别标注;版本过旧或来源冲突 → 并列差异 + 标「待确认」;
- 限值类结论引用规则库 RULE-*(规则库速查条目),不自己发明限值;
- 版本号与条目 id 只能来自检索命中,不得虚构 —— 没有 citation 支撑的「条文」不存在。

## 无命中话术(检索无命中必须明说,禁止编造条文)

```
检索结果:知识库无命中(查询:SCR-300 维保周期 油品型号)。
已核对语料清单,现有域语料:设备手册 / 工艺卡 / 预警规则库 / 处置案例(样例)。
按纪律:不编造条文、不给猜测数值、不拿邻近设备语料冒充。
待确认:请提供 SCR-300 随机资料,或由资料员走知识提案评审补录(未过审不进检索);补录后再查。
```

- 「直接告诉数值」的催促不豁免纪律:无命中 = 明说无命中,不给编造值;
- 弱相关命中(片段答非所问)视同无命中,不挑半句拼答案;
- 分工:基座通用 wiki 走 knowledge_search(@basis/knowledge),本包域语料走 kb_search —— 都经 Knowledge MCP,不经公网。

## 红线速查

- 知识层只经 Knowledge MCP(pgvector+图谱)访问:直连向量库/图库即越界(deny,fail-closed);
- 语料修订走知识提案(knowledge_propose,评审通过才进检索),不直改;限值修订属工艺变更,走正式流程;
- 知识给「应该」,实测给「实际」:与时序/预警互证时矛盾如实并列,不调和、不替现场拍板。
