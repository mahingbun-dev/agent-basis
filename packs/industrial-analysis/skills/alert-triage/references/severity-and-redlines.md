# 分级口径与红线速查(alert-triage references)

## 分级(对齐规则库;规则没写的给建议分级 + 依据,并标待确认)

- **P0**:安全/联锁限值被突破或即将突破(如压力超跳机限值)→ 立即处置,升级到调度;
- **P1**:劣化趋势明确、影响质量或设备寿命(如温度连续越限、振动超 C 区)→ 限产/重点监控,
  升级到设备/工艺;
- **P2**:短时越限、已回落或低限类提示(如流量骤降后恢复)→ 计划检修/记录在案。

## 处置建议三段式

```
即时动作:带负荷侧的立即项(谁、做什么、时限);
参数核查:对照测点与限值(引用测点 + 时间窗 + RULE-*);
升级路径:班组→工艺→设备→调度,触发条件写清。
```

## 红线速查

- 写回仅限预警记录表(alert_records):达梦其余表只读,静默写库=失败;
- 数据与规则只经 MCP 读取,不直连库、不要求贴库凭据;
- 对外通报是 R2:起草全文 → 确认 → 再发;确认通道未接入前一律 withhold,不做裸发射;
- 绝不编造测点数据与预警记录;deny 优先、fail-closed:规则未放行即拦截。
