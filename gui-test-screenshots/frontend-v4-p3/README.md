# v4「温润如玉」前端改造 · P3 验收截图

生成方式：真实浏览器（agent-browser / CfT Chromium）对**与生产同构的静态探针**截图。
探针页复用了 `injectDesignTokens({bridge:true})` 的实际下发链路（品牌令牌 +
`:root{SHARED}` + 宿主桥接 + 组件 CSS），因此这组截图反映的是真实渲染结果，
而不是另画一份 CSS。

深色条件：宿主真实的 `body[data-ds-dark-theme]`（不是 `prefers-color-scheme`，
上游没有这条媒介查询）；浅色另设 `data-eterna-theme='light'` 锁定。

## 逐项自查（对应 frontend-style §7 清单）

- 三视口无横向溢出：390 下 `scrollWidth ≤ innerWidth`（工作台看板是列内横向滚动，
  不是整页溢出）；设置弹窗单列、内距 16。
- 圆角全部取阶梯值：卡片 22(lg) / 输入与徽标 12(sm) / 按钮 16(md) / 登录右卡 28(xl)；
  嵌套满足同心弧。
- 字重只出现 400/500/600；正文不再有 500。
- 正文 15px、说明行 13px、元数据 12px；11px 只用于纯标注。
- 强调色每屏 ≤2 处（登录：黛青按钮 + 眉标；设置：主按钮 + 链接）。
- 决策层贴在输入卡顶边向上浮出，倒计时条贴卡片顶边，z=200（低于宿主 toast 1100）。
- 深色下所有容器自带文字基线（`--et-fg`），无继承浏览器默认黑。

## 两处已知的探针（非产品）缺陷，已修

1. 裸 `SHARED` 声明在 `:root` 外层时，解析器会吞掉紧随其后的规则——必须包进 `:root {}`。
2. 工作台根容器 `height:100%` + 自身滚动，直接挂 body 下会被页面滚动顶出视口——
   必须包进定高宿主管道（`height:100vh; overflow:hidden` 的父容器）。
