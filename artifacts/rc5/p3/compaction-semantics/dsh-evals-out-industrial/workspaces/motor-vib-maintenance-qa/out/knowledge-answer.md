# 知识问答:2#线电机轴承振动超限的维护处置(样例语料,Knowledge MCP 接入前桩内样例)

## 结论
2#线电机轴承振动 4.8 mm/s 超 ISO 10816 C 区限值 4.5(RULE-VIB-ISO10816)。
按维护手册处置路径:轴承点检 → 润滑确认 → 对中复查 → 视情更换轴承;
连续 3 点越限即升级设备主管。
