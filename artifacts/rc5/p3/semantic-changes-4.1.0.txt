三、4.0.6-alpha.1 -> 4.1.0 语义变更清单(供 PR 描述)
  1. LoggerLevel 数值反转:WARN=1 / INFO=2(原 INFO=1 / WARN=2)。按数值比较级别的
     exporter/消费方必须复核;本仓 v1 六插件无按数值比较的用法(grep 已确认)。
  2. Events 接口:
     - internal/config(fiber, next)(原 (this: Fiber, config, next));
     - 新增 internal/commit(fiber, originalConfig);
     - internal/update(config, next) 去掉 noSave,返回 Awaitable<void>;
     - 新增 symbol 索引签名;internal/dispatch 名称类型放宽为 string | symbol。
  3. EventsService:
     - register/unregister 改私有(原公开);
     - once 接受 symbol;
     - parallel 上报的 dispatch 模式修正为 'parallel'(原误报 'emit')。
  4. Fiber:
     - config 语义改为 raw input(原 validated);rawConfig 读写同一字段;
     - effectiveConfig 单独存放(_effectiveConfig),仅激活/成功 update 后发布;
     - store 退役 -> committed(依赖快照)+ provisions(自有提供);
     - update() 返回 Awaitable<void>;
     - FAILED fiber 不再因依赖变化自动恢复,须显式 update();
     - 卸载先等 dependents 完成,再撤自身 effects;被取代的加载失败只记日志。
  5. reflect.Impl:
     - fiber 字段 -> ctx;新增 uid / dependents / release / isolate;
     - provide disposer 等待 dependents;notify() 返回 void(原返回 fiber 列表);
     - 服务解析优先 committed,再按 provisions 的 isolate 匹配。
  6. utils:
     - 新增 symbols.caller;
     - createShadow/createTraceable 区分 defSite(服务解析)与 useSite(intercept/isolate/effects);
     - createCallable 走 Reflect.apply;apply 分支为 proxy 生成 shadow receiver。
  7. context.ts:baseUrl?: string | undefined(exactOptionalPropertyTypes 友好)。
  8. FiberState 数值/导出名不变;CordisError 码表不变。
